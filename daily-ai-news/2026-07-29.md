## 1. Kimi K3：首个开源 3T 级 Frontier 模型发布

**来源**：MoonShot AI | [arXiv:2607.24653](https://arxiv.org/abs/2607.24653) | [GitHub](https://github.com/MoonshotAI/Kimi-K3) | [官方博客](https://www.kimi.com/blog/kimi-k3)

**事件简述**：月之暗面发布 Kimi K3，2.8T 参数 MoE 模型（104B 激活参数），原生视觉能力，100 万 token 上下文窗口。架构创新包括 Kimi Delta Attention + Attention Residuals（改善长序列信息流）、Stable LatentMoE（896 专家中每 token 激活 16 个）。相比 K2 整体扩展效率提升约 2.5×。后训练覆盖通用 RL、Agent RL、Coding RL 多强度推理。**完整模型权重已开源**。

**值得关注的原因**：
- **Agent 能力强悍**：OSWorld-Verified #1（84.8%）、TerminalBench 2.1 #2（88.3%）、FrontierSWE #2（81.2%）、BrowseComp #3（91.2%）。它是首个在 Agent/Coding 综合能力上系统性接近闭源顶级的开源模型。
- **视频理解突破**：Video-MME #1（90.0%，with subtitles）、MMVU #1（82.1%），说明"原生视觉预训练 + 百万上下文"是长视频理解的正确方向。
- **开源意味着可复现可魔改**：相比 GPT-5.6 Sol / Claude Fable 5 等闭源模型，K3 的全权重开源让学术界可以研究其 Agent 行为、推理链、工具使用模式，这对 Agent 研究是基础设施级别的提升。

**技术启发**：百万上下文 + 原生视觉 + Agent RL 的组合暗示 Video Agent（处理长视频做决策）的技术路线正在成熟——可以用 K3 作为基座研究"观看长视频→制定计划→执行工具调用"的闭环。

## 2. WorldDiT：统一扩散架构同时做世界建模与动作生成

**来源**：Bagel Labs | [arXiv:2607.23909](https://arxiv.org/abs/2607.23909)

**事件简述**：提出 WorldDiT，在单个 Diffusion Transformer 中同时完成连续动作块生成和未来 RGB patch 预测。仅 399M 参数即在 LIBERO 四套件上达到参数-成功率 Pareto 前沿——任何成功率更高的方法参数都更大，任何参数更少的方法成功率都更低。训练时使用 flow-matching 统一动作和视觉目标，推理时仅需动作分支。

**值得关注的原因**：
- **直接打击视频×具身交叉点**：WorldDiT 证明"世界预测"和"动作生成"可以在单一模型中共训练并相互受益，而不需要 7B+ 的大 VLM 做动作骨干。
- **极简基线价值**：399M 参数就能到 Pareto 前沿，意味着这是一个极好的消融实验起点——后续研究者可以在其上叠加各种设计选择并隔离测量各自贡献。
- **"小模型也能打"的信号**：延续了上周 Patch Policy（0.7% 参数超越 OpenVLA）的叙事——具身智能不一定要靠参数堆砌，好的架构和数据配方更重要。

**技术启发**：WorldDiT 的训练范式（flow-matching 统一视觉+动作）可以推广到视频预测→动作生成的联合训练。一个有趣的方向是：在 WorldDiT 的框架中加入视频理解模块（如时序事件定位），让模型不仅预测未来帧，还能理解"正在发生什么"。

## 3. Data Pyramid for Embodied Manipulation：具身数据的"营养金字塔"

**来源**：北京大学 | [arXiv:2607.24744](https://arxiv.org/abs/2607.24744) | HuggingFace 62🔥

**事件简述**：28 位作者（含穆尧等）联合撰写的重磅综述，将具身操作数据组织为五层"金字塔"：真实机器人数据 → UMI 数据 → 自我/外部中心数据 → 仿真数据 → 通用视觉-语言数据。每层按可扩展性、机器人对齐度、质量、多样性、可复用性、物理保真度六个维度系统对比。进一步分析了近期具身基础模型（Embodied Brain Models、VLA、WAM）的数据配方，并提炼六大开放挑战。

**值得关注的原因**：
- **回答了一个根本问题**：具身智能到底需要什么数据？综述给出了可操作的数据配方框架，而不是空谈"more data"。
- **六个开放挑战都是研究金矿**：大规模触觉数据集、失败与恢复数据、可扩展采集管线、跨本体动作对齐、自我中心数据用于灵巧操作、原则化数据配方设计——每个方向都有明确的学术贡献空间。
- **视频数据的定位被明确**：自我中心/外部中心视频处于金字塔中层，提供"丰富的人类交互先验"，但如何桥接 human video → robot action 仍是开放问题——直接对应视频分析与具身智能的交叉研究。

**技术启发**：作为视频分析方向的研究生，可以重点关注"利用 egocentric video 预训练提升机器人灵巧操作"这一方向——目前缺乏大规模触觉标注，但视频中的物理交互信号（物体运动、接触、形变）可能可以作为替代监督信号。

## 4. Embodied GPT-5.1：没有身体的 LLM 也有世界模型？

**来源**：Roberto Spinelli 等 | [arXiv:2607.23899](https://arxiv.org/abs/2607.23899)

**事件简述**：一项探索性研究将 GPT-5.1 作为物理移动机器人的高层控制器——**零具身训练、零仿真经验、零传感器运动接触**。仅输入低分辨率第一视角图像和离散动作集，GPT-5.1 展现出：短时记忆（物体离开视野后仍记得位置）、物理推理（推断自身运动后果）、连贯动作序列（碰撞物体后倒车验证结果）。

**值得关注的原因**：
- **直接挑战认知科学信条**：传统观点认为物理身体是发展空间智能的前提，但 GPT-5.1 的表现暗示"世界模型"可能从语言+视觉的互联网规模预训练中涌现。
- **Agent×具身的实验范式**：这是"零样本具身 Agent"的极端测试——不做任何微调，直接把 LLM 接到机器人上。方法论上有借鉴价值。
- **效率问题也是研究方向**：论文同时暴露了感知局限（精确对齐策略不精确、远处干扰物误判），这些正是视频分析（更好的视觉表征）和具身学习（高效的微调方法）可以介入的地方。

**技术启发**：可以用类似范式测试 Kimi K3 等开源模型在零样本具身控制上的表现——开源模型有完整权重和训练细节，可以更精细地消融哪些预训练成分贡献了涌现的物理理解能力。

## 5. LeapBot-WA：用 JEPA 范式重构世界动作模型

**来源**：Pei Liu 等 | [arXiv:2607.23969](https://arxiv.org/abs/2607.23969) | [Code](https://github.com/leapbot-wa)

**事件简述**：提出 LeapBot-WA，将 JEPA（Joint-Embedding Predictive Architecture）引入 WAM，把世界建模从像素生成转向预测性语义对齐。核心创新：(1) Isotropic Semantic Autoencoder 将 JEPA 的非高斯预测特征映射到扩散友好的流形；(2) 非对称 MoT 架构——训练时 Anchor Diffusion Transformer 作为特权动力学专家指导 Action Diffusion Transformer，推理时剪枝零开销。LIBERO 上预测类模型 SOTA，RoboTwin 2.0 上匹敌顶级生成式 WAM，且无需大规模轨迹预训练。

**值得关注的原因**：
- **范式级创新**：JEPA（LeCun 推崇的自监督路线）首次被系统性地植入 WAM。"不重建像素，只预测语义对齐"的思路可能比像素级视频生成更高效、更鲁棒。
- **训练-推理解耦设计**：非对称 MoT（训练时 heavy anchor，推理时 pruned）是巧妙的设计模式，值得在其他具身模型中推广。
- **对视频分析方向的启发**：如果"不重建像素"就够了，那么视频表示学习的目标不应该是对抗生成质量（FVD/PSNR），而应该是"能否从中解码出正确动作"——这改变了视频生成在机器人中的角色定位。

**技术启发**：LeapBot-WA 的 ISAE（把非高斯特征压缩到扩散流形）技术可以用于视频压缩——在保证下游任务（如动作识别、时序定位）性能的同时大幅降低视频存储/传输成本。这是一个视频编码×具身智能的有趣交叉。

## 趋势观察

1. **开源 Frontier 模型进入 Agent 时代**：Kimi K3 全权重开源标志着"强 Agent 能力"不再是闭源模型的专属。学术界可以开始系统性地研究 Agent 的内部机制。
2. **WAM 路线多元化**：本周同时出现 WorldDiT（统一扩散）、LeapBot-WA（JEPA 预测性潜在）、Data Pyramid（数据配方指南），WAM 的设计空间正在从"像素生成"的单一路线快速分化为多条技术路径。
3. **"零样本具身"成为新测试基准**：Embodied GPT-5.1 打开了"不微调直接用 LLM 控制机器人"的实验范式，这对评估视觉-语言模型的真实物理理解能力很有价值。
4. **"小模型+好设计 > 大模型"持续验证**：WorldDiT 399M 达到 LIBERO Pareto 前沿，与上周 Patch Policy（0.7% 参数超越 OpenVLA）形成共识信号。
